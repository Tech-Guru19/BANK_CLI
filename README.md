# 🏦 BANK_CLI — Modern Banking Dashboard

A full-stack **banking experience** with a polished, professional UI. The React client delivers an elegant indigo-and-teal dashboard for accounts, transactions, and transfers, backed by a local Express API.

> ⚠️ This is a **demo / learning project** — no real financial operations are performed.

## ✨ Features

- 👤 **Account overview** — balances and account cards at a glance
- 💸 **Transfers & transactions** — send money between accounts, view history
- 📈 **Trends** — income/expense insights with icons and filters
- 🖨️ **Export & print** — download and print statements
- 🔐 **Per-account state** — localStorage keys scoped by account number
- 🎨 **Beautiful UI** — gradients, glassy cards, smooth animations, Lucide icons

## 🧱 Tech Stack

| Part | Tech |
|---|---|
| Client | React (Vite), Bootstrap, Lucide React, Axios |
| Server | Node.js, Express 5, CORS |

## 🚀 Getting Started

```bash
git clone https://github.com/Tech-Guru19/BANK_CLI.git
cd BANK_CLI

# Server
cd Server && npm install && npm start   # runs on port 5000

# Client (new terminal)
cd ../Client && npm install && npm run dev
```

## 🗂️ Structure

```
BANK_CLI/
├── Client/    # React + Vite dashboard
└── Server/    # Express API (localhost:5000/api)
```
